Legal & Provenance Manifesto

How MicaNT strictly adheres to established fair use jurisprudence, software interoperability standards, and automated clean-room verification.

1. Judicial Fair Use Precedent: Google LLC v. Oracle America, Inc.

593 U.S. 1 (2021) • Decided April 5, 2021

In a landmark 6–2 decision written by Justice Stephen Breyer, the Supreme Court of the United States ruled that the reimplementation of an application programming interface (API), method declarations, naming conventions, and functional system hierarchies constitutes fair use as a matter of law.

"Where Google reimplemented a user interface, taking only what was needed to allow users to put their accrued talents to work in a new and transformative program, that copying was a fair use of that material as a matter of law."

MicaNT reimplements declaring function signatures, NTSTATUS numeric codes, and system call numbers solely to enable binary interoperability for existing 64-bit software binaries, device drivers, and applications.

2. Circuit Court Clean-Room Precedents

Two foundational Ninth Circuit decisions firmly establish the legality of clean-room functional reimplementation:

  • • Sega Enterprises Ltd. v. Accolade, Inc. (977 F.2d 1510, 9th Cir. 1992):
    The court held that studying interfaces and functional constraints for the purpose of achieving compatibility is fair use, stating that copyright does not extend to the functional characteristics of software under 17 U.S.C. § 102(b).
  • • Sony Computer Entertainment, Inc. v. Connectix Corp. (203 F.3d 596, 9th Cir. 2000):
    The court affirmed that reverse-engineering proprietary firmware to produce a clean, independent implementation of a platform's execution environment is transformative and fully protected by fair use.

3. Official MIT-Licensed Upstream References

Rather than relying on closed or proprietary header files, all data structures, GUID definitions, and API interfaces in MicaNT are derived from Microsoft’s officially published open-source repositories licensed under the permissive MIT license:

microsoft/win32metadata
Official MIT-licensed Win32 API metadata schema defining structures, unions, and system calls.
microsoft/DirectX-Headers
Official MIT-licensed DirectX 11/12 and DXGI interface headers utilized for PrismX presentation.

4. Automated Clean-Room Sentinel CI Pipeline

Every pull request and commit to the MicaNT repository is scanned by an automated verification script (scripts/clean_room_sentinel.js) executed as part of the GitHub Actions CI workflow:

  • ✓ AST Marker Scanning: Scans all C++23 source files for proprietary Microsoft internal markers, disclaimers, or NDA artifacts.
  • ✓ Zero Binary Blobs: Rejects any binary PE/COFF files, pre-compiled object files, or closed-source DLLs.
  • ✓ Clean-Room Authorship: Confirms that every line of executive code is an original implementation authored under the MIT License.
