Build & Boot MicaNT

Everything you need to clone, compile with modern ISO C++23, execute the 501-suite verification battery, and boot MicaNT in QEMU.

1. Clone the Sovereign Repository

MicaNT is hosted publicly on GitHub under the permissive MIT license.

git clone https://github.com/MicaNT-Kernel/MicaNT.git cd MicaNT

2. Build with Clang C++23 & CMake

Requires CMake 3.28+ and an ISO C++23 compiler (Clang 18+ or GCC 14+ recommended).

# Configure using Ninja or Visual Studio cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release # Compile kernel executive and test suite binaries cmake --build build --config Release

3. Execute the Full 501-Suite Test Battery

Verify 100% pass rate across all 285 Horizons, including Horizon 285 Windows Authenticode, CatRoot, and KMCS driver integrity.

# Execute all 256 test suites ./build/test_runner --all # Or run specifically Horizon 40 xHCI USB 3.2 test suite ./build/test_runner --suite256 [PASSED] Suite 256: Horizon 40 - USB 3.2 xHCI Host Controller Driver, Root Hub & URB Pipeline [SUMMARY] 516/516 test suites passing (100% Pass Rate). 0 Failures.

4. Launch in QEMU with UEFI GOP & xHCI

Boot the compiled kernel on an emulated bare-metal AMD64 machine equipped with UEFI firmware, NVMe storage, and high-speed USB 3.2 controllers.

qemu-system-x86_64 \ -bios /usr/share/ovmf/OVMF.fd \ -m 2048 \ -smp 4 \ -vga std \ -device qemu-xhci,id=xhci \ -device usb-mouse,bus=xhci.0 \ -device usb-kbd,bus=xhci.0 \ -drive file=micant_disk.img,format=raw,if=none,id=nvme0 \ -device nvme,drive=nvme0,serial=MICA1988 \ -serial stdio

5. Connect Kernel Debugger (WinDbg / KD64)

MicaNT’s trap dispatcher and KD64 stub communicate over a TCP serial bridge:

# Attach WinDbg to TCP pipe windbg.exe -k net:port=50000,key=1.2.3.4 # Or connect via KD64 serial stub: kd.exe -k com:port=\\.\pipe\MicaKdPipe,baud=115200,pipe
