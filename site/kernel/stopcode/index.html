Sovereign Crash Dump Analysis

How to inspect triage memory dumps generated by MicaNT’s TitanCrashDumpEngine.

📂

Minidump Storage Location

Crash dumps are written to \DosDevices\C:\Windows\Minidump\Minidump_YYYYMMDD_HHMMSS.dmp (or NVMe block sector 0x1000 in fallback halts). Size is restricted to 256KB triage buffers to prevent stalling.

🔍

WinDbg / KD64 Commands

Open the triage dump in standard WinDbg or KD64 and run: !analyze -v to parse the DUMP_HEADER64, r to examine AMD64 register context, and kn to inspect the unwound callstack.

🎨

Customizing Crash Screen Theme

To change the crash screen color palette across your system: reg.exe add HKLM\SYSTEM\CurrentControlSet\Control\CrashControl /v CrashScreenTheme /t REG_DWORD /d 0 (0 = Midnight Obsidian, 1 = Emerald Prism, 2 = Royal Navy).
