Horizon 40
🔌

USB 3.2 xHCI Host Controller & URB Pipeline

MicaNT implements the complete Extensible Host Controller Interface (xHCI 1.2) specification. Features MMIO Capability and Operational register banks, 64-entry Device Context Base Address Array (DCBAA), Command Ring, Event Ring with Event Ring Segment Table (ERST), and per-endpoint Transfer Rings with chained Scatter-Gather Transfer Request Blocks (TRBs). Includes full asynchronous USB Request Block (URB) dispatching and Root Hub PnP enumeration (PCI\VEN_8086&DEV_02ED → USB\ROOT_HUB30).

⚡

Pure Object Manager (ob/)

Directly inspired by Dave Cutler’s DEC PRISM and Windows NT Object Manager. Provides a unified, hierarchical namespace (\Device, \DosDevices, \KernelObjects, \BaseNamedObjects). Every kernel entity (File, Process, Thread, Mutex, Event, Semaphore, Section) is represented as an Object Header with type descriptors, atomic reference counts, handle table entries, and access mask validations.

🛡️

Security Trinity (SAM, LSASS, Winlogon)

Clean-room implementation of the sovereign Windows security subsystem: SAM user account database with RFC 1320 MD4 NT-Password hash generation; LSASS process hosting the MSV1_0 authentication package with cryptographically secure NTLM challenge/response verification; and Winlogon secure desktop isolation managing user sessions and primary token synthesis.

🎮

PrismX & Prism3D Graphics Engine

DirectX 11/12 and Vulkan 1.3 presentation engine built without proprietary headers. Implements IDXGIFactory1, IDXGISwapChain (with FLIP_DISCARD presentation models), software barycentric Gouraud triangle rasterizer with Z-buffer depth testing, and WDDM kernel thunking (dxgkrnl.sys / D3DKMT).

💾

NTFS & FAT32 Storage Drivers

Zero-dependency, clean-room filesystem engines: Full 1024-byte NTFS Master File Table (MFT) record parser, non-resident runlist decompressor, multi-extent file reading, and B-Tree index allocation. Paired with a resilient FAT32 cluster chain crawler and Virtual File System (VFS) mount table.

🌐

NDIS 6.x & RFC 793 TCP/IP Stack

Dual-stack IPv4 and IPv6 network pipeline implementing ARP resolution, ICMP echo requests/replies, UDP datagram processing, and a full RFC 793 11-state TCP state machine (LISTEN, SYN_SENT, SYN_RECEIVED, ESTABLISHED, FIN_WAIT, CLOSE_WAIT, etc.). Exposes a standard Winsock 2 (ws2_32.dll) userland API.

⏱️

Preemptive Scheduler & Quantum Accounting

Multicore AMD64 scheduler featuring 32 priority levels divided into Real-Time (16–31) and Variable (0–15) classes. Implements round-robin quantum tracking, priority boosting upon I/O completion, inter-processor interrupts (IPI), and low-latency task state segment (TSS) context switching.

🚨

Titan Crash Dump Engine (BugCheck)

High-reliability crash dump writer that operates at elevated IRQL (HIGH_LEVEL / 0x1F). Bypasses memory paging to write triage minidumps directly to NVMe/AHCI block sectors, captures full CONTEXT64 AMD64 register state and unwound stack frames, and presents the multi-theme sovereign crash screen.

⚙️

Service Control Manager (SCM)

Clean-room services.exe daemon managing system services, automatic/manual startup dependencies, state transitions (START_PENDING, RUNNING, STOP_PENDING), and shared svchost.exe service host worker isolation via Named Pipe RPC.
